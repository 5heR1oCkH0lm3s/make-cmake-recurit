# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理

    预处理器主要对源码进行纯文本层面的替换与整理。它会处理所有以 `#` 开头的预编译指令，包括展开宏定义（`#define`）、递归地将头文件（如 `<stdio.h>`）中的声明完整复制进当前文件，并删除代码中的所有注释。此阶段输出扩展名通常为 `.i` 的预处理文件，本质依然是人类可读的 C 语言文本。
2. 编译

    编译器对预处理后的代码进行词法分析、语法分析、语义检查以及代码优化。在确认代码无语法错误后，将其翻译成与目标机器架构对应的底层汇编指令（如操作寄存器的 `mov`、`push`、`call` 等）。输出的文件通常为 `.s` 结尾的纯文本汇编代码。
3. 汇编

    汇编器将上一步生成的汇编指令逐条翻译成 CPU 能够直接执行的二进制机器指令（0 和 1）。此阶段生成的文件为目标文件（通常为 `.o`），它已经是二进制格式，包含了程序的机器指令与数据段，但因为缺乏符号地址绑定，尚不能直接独立运行。
4. 链接

    链接器将一个或多个目标文件与所需的系统标准库（如 `libc` 提供的 `printf` 实现）进行组装。它的核心任务是解析外部符号的地址并进行重定位，最终打包合并为一个包含完整入口地址、具备系统可执行权限的最终文件。
